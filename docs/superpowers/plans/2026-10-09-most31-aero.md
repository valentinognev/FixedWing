# MOST31 Generalized Aero Model Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this plan task-by-task, dispatching the parallel waves below together. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** One radian-based aero evaluator, MOST31, that exactly reproduces X-31 Figure 2.2, F-16 Morelli and F-16 Stevens from translated coefficient files, and is the aero path of both the F-16 and the X-31 plants.

**Architecture:** New `python/most31/` package: fixed dense schema + loader, one evaluator (polynomial tensor + four table kinds + CG shift + wind→body), three translators, and a build CLI that writes three committed JSON files. `f16/model._coefficients` evaluates MOST31. A FixedWing-owned `python/x31_plant.py` mirrors the port's plant step with only the aero swapped; `x31_sim.py` and `x31_guidance.py` call it. The old evaluators stay as translation source and test oracle.

**Tech Stack:** Python 3, numpy, unittest. Host-only (`cd python && python3 -m unittest <module> -v`). No Docker, PX4, network.

**Spec:** `docs/superpowers/specs/2026-10-09-most31-aero-design.md` — read it before your task; it holds the math, the slot mapping and the tolerances.

## Review Focus

1. **Negative α and β = 0 exactly.** `sgn(0) = 0`, X-31 odd polynomials at negative α (`-P + 2c6`), Stevens `cl`/`cn` `* sign(beta)` at β = 0 — owned by Tasks 2, 4, 5 (cases in the shared grid include α < 0 and β = 0).
2. **Outside the Stevens grid.** α below −10° and above 45°, |β| above 30°, elevator beyond ±24° must extrapolate from the end segment exactly like the AeroBench clamps — Task 4 grid includes α −30°, 47°, 85°, β ±35°, elevator ±25°.
3. **Off-reference CG.** `xcg != xcgref` shifts `Cm`/`Cn` using body totals including rate terms; wind forces never shift — Task 2 unit test, Tasks 3/4 oracle runs at `xcg = 0.30, xcgref = 0.35`.
4. **Cached arrays mutated by a caller.** `load()` caches per path; returned arrays are read-only so one caller cannot corrupt another — Task 1 test.
5. **Closed-loop X-31 numeric drift.** 1e-13-level aero differences under adaptive `ode45` must not move existing runner assertions — Task 9 runs the full X-31 suite and reports any changed number with its magnitude.

### Task 5: X-31 Figure 2.2 translator  *(wave 3)*

**Files:** Create `python/most31/translate_x31.py`, `python/tests/test_most31_x31.py`.

**Interfaces — Produces:** `translate_x31(table: np.ndarray, source: str) -> Most31Coefficients`; `table` shape `(10, 2, 8)` as `x31.params.fig22()` returns; flags other than 0/1 raise `ValueError`.

Rows `[row, col]`: 0 `(CL, CD)`, 1 `(CLdc, lift_offset)`, 2 `(CY, CYdr)`, 3 `(Clb, Cnb)`, 4 `(Clp, Cnp)`, 5 `(Clr, Cnr)`, 6 `(Clda, Cnda)`, 7 `(Cldr, Cndr)`, 8 `(Cm0, Cmq)`, 9 `(Cmdc, moment_offset)`.

Algorithm (non-obvious): represent an α-function as `F = (2, 13)` array, `F[0]` even part, `F[1]` odd part, so `f = Σ F[0,n]|α|^n + sgn(α) Σ F[1,n]|α|^n`. From a port row `c`: `F[0,0] = c6`; powers `c_i * k^i` (i = 1..6) go to `F[1, i]` if flag 1 else `F[0, i]`. Product `H = F ⊗ G`: `H[0] = conv(F[0], G[0]) + conv(F[1], G[1])`, `H[1] = conv(F[0], G[1]) + conv(F[1], G[0])`, truncated to n ≤ 12 (higher entries must be zero — assert). A slot write puts `F` into `poly[o, m, :, :, j, 0]`.
