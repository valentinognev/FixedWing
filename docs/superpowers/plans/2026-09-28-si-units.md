> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make the in-tree F-16 plant speak SI (metres, m/s, radians, newtons) while AeroBench and `f16dynamics` stay imperial behind `units.py`.

**Architecture:** `python/f16/units.py` is the only converter and owns the scaled constants. The Morelli derivative, LQR, and outer gains run in SI. `compare.py` converts SI↔imperial only when it calls the read-only references. CSV stays NED metres (+z down). Time stays seconds.

**Tech Stack:** Python 3, numpy, scipy RK45 (existing `run_sim`), unittest (`cd python && python3 -m unittest <module> -v`). Host-only. No Docker, MAVLink, ZMQ, PX4, network, or `fgfs`.

**Spec:** This plan is the spec. Binding scope is the 2026-09-28 SI ruling in Global Constraints. Plant shape and scenarios come from `docs/superpowers/specs/2026-09-27-f16-gcas-design.md` plus the behaviour already on the `f16-cpp-parity` baseline (`gcas_long`, C++ probe, ACAS skip).

## Global Constraints

- Host-only tests: `cd python && python3 -m unittest <module> -v`. No Docker, MAVLink, ZMQ, PX4, network, or `fgfs`.
- Morelli only. `subf16_derivative(..., model="stevens")` raises `ValueError`. Default `model="morelli"`.
- `python/f16/units.py` is the only converter. Call sites do not multiply by `0.3048` or by `pi/180` themselves.
- Foot = `0.3048` m exactly (`M_PER_FT`). Degree/radian uses `math.pi / 180` (`DEG_TO_RAD`). AeroBench's alpha scale `57.29578` (`AEROBENCH_RTOD`) lives in `units.py` and is not a second public degree converter.
- In-tree 13-state is SI, altitude **positive up**: vt m/s, alpha/beta/phi/theta/psi rad, p/q/r rad/s, pn/pe m, h m, power 0–100. Controls: throttle 0–1, elevator/aileron/rudder rad. Internal force is newtons. `Nz` and `Ny` stay load factor in g. Integrators 13–15 are unchanged (g·s, rad, g·s).
- `u_ref` is `(Nz g, ps rad/s, Ny_r, throttle)`. It is not a surface command and is not scaled.
- Paper `xequil` / `uequil` / `K_lqr` and the straight-and-level `k_alt` / `K_vt` are transformed. Live numbers must not stay equal to the imperial paper row.
- Parity still compares to imperial AeroBench and `f16dynamics` through `state_si_to_imp` / `u_si_to_imp`. Altitude gate is `15.24` m (`50 * 0.3048`). `final_rms` stays `<= 5.0` after mapping the SI 13-state back to imperial (angles and power do not scale; do not replace 5.0 with `1.524`).
- Python `gcas_long` compare stays `115` s because AeroBench stops below `60.96` m/s (200 ft/s) near t = 118 s. Time is seconds. Runner horizon and the C++ pair stay `120` s. Do not claim the Python compare runs to 120 s.
- Bad setup exits 2 with one stderr line before `run_sim`. `gcas_floor_ft` is that failure. Shipped key is `gcas_floor_m` = `304.8`.
- ACAS probe still skips when `csaf_f16` or `f16dynamics` is missing. Do not port ACAS.
- Balloon-race code that is already NED metres stays metres. Do not retune race gains. `python/fw_sitl/**`, `python/flightSetup.json`, and calibration are out of scope.
- FG/JSBSim still speak feet at their own property boundary (`balloon_scene.py` `elevation-ft`, `spawn_ic.py` `vt` `FT/SEC`). That is a later plan. Those files do not talk to `python/f16/`.

        self.RudderMinRad = deg_to_rad(-30)
        self.NzMax = 6
        self.NzMin = -1

        self.K_lqr = np.zeros((3, 8))
        self.K_lqr[:1, :3] = _K_LONG_DEG * DEG_TO_RAD
        self.K_lqr[1:, 3:] = _K_LAT_DEG * DEG_TO_RAD

        self.uequil = u_imp_to_si(_U_IMP)

        self.model_str = "morelli"

    def get_u(self, u_ref4, x_f16):
        u_ref4 = np.asarray(u_ref4, dtype=float)
        x_f16 = np.asarray(x_f16, dtype=float)
        x_delta = x_f16.copy()

        u[3] = max(min(u[3], lim.RudderMaxRad), lim.RudderMinRad)
        return x_ctrl, u

        return 3

    def get_integrator_derivatives(self, t, x_f16, u_ref4, Nz, ps, Ny_r):
        return [Nz - u_ref4[0], ps - u_ref4[1], Ny_r - u_ref4[2]]

    def __init__(self, alt_m: float, vt_mps: float, llc) -> None:

def compare_trajectories(a: dict, b: dict) -> dict:
    from f16.units import state_si_to_imp
