# F-16 Wings-Level Trim Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Port AeroBench `trimmerFun` wings-level trim (orient 1) onto the in-tree SI Morelli plant, then print that trim and its SI state-space matrices for a requested Mach and geometric height.

**Architecture:** `python/f16/trim.py` owns the search and the linearization. The cost is `clf16` orient 1: throttle, elevator, and angle of attack are free; airspeed and height are fixed; `conf16` sets θ = α, zero body rates, and power = `tgear(throttle)`. Accelerations inside the cost are converted to AeroBench units before the MATLAB weights, because `vt_dot` in the plant is m/s². The minimizer is SciPy Nelder-Mead with the same tolerances `trimmerFun` passes to `fminsa`. `jacobFun` is reimplemented on the SI derivative with the same shrink loop and no interactive prompt. `run_f16_trim.py` plus `run_f16_trim.sh` are the only callers. `F16Llc` keeps the frozen paper bias; this search does not replace it.

**Tech Stack:** Python 3, numpy, scipy 1.18.0 (`scipy.optimize.minimize`, method `Nelder-Mead`), unittest (`cd python && python3 -m unittest <module> -v`). Host-only. No Docker, MAVLink, ZMQ, PX4, network, or `fgfs`.

**Spec:** This plan is the spec. Binding scope is the Global Constraints below. It follows the SI plant in `docs/superpowers/plans/2026-09-28-si-units.md` (UPDATES `0.79.0`). MATLAB sources, read-only: `../F16/AeroBenchVV/F16_Sim/F16_Model/NonlinearModel/trimmerFun.m`, `clf16.m`, `conf16.m`, `jacobFun.m`, and `../F16/AeroBenchVV/F16_Sim/F16_Model/getLinF16.m`.

## Global Constraints

- Wings-level, γ = 0 only. Do not port orient 2 (climb), orient 3 (level turn), or orient 4 (pull-up). Do not add those flags to the CLI.
- Do not edit `python/f16/llc.py`, `python/f16/model.py`, `python/f16/sim.py`, or `python/f16/units.py`. Import `_adc` and `_tgear` from `f16.model`. Do not copy the throttle-gear equation.
- Do not edit `../F16/AeroBenchVV`, `../F16/AeroBenchVVPython`, or `../F16/f16-flight-dynamics`.
- Public state is the SI 13-vector. Public controls are throttle 0–1 and surfaces in radians. `Nz` and `Ny` stay load factor in g. Geometric height is `x[11]` metres, positive up, not NED down.
- Nominal flight condition of the frozen paper row, from `_adc(fts_to_ms(502), ft_to_m(1000))`: Mach `0.4511192456`, height `304.8` m, airspeed `153.0096` m/s. The e2e search uses this pair.
- The frozen paper row is not a root of this plant. At `state_imp_to_si(_X_IMP)` / `u_imp_to_si(_U_IMP)` the orient-1 cost is about 14.4 (`q_dot` ≈ −0.187 rad/s², `Nz` ≈ 0.145). A correct search must not be asserted equal to `_X_IMP` / `_U_IMP`. Those constants stay the LQR bias.
- SciPy 1.18.0 Nelder-Mead, `adaptive=False`, `xatol=1e-9`, `fatol=1e-9`, `maxiter=1000`, started from `s0 = [0.2, 0.0, 0.0]` (throttle, elevator degrees, α radians — the `getLinF16` guess), at the nominal Mach and height, returns cost `< 1e-7` and:
  - throttle `0.11707336` (atol `5e-5`)
  - elevator `−1.80138335` deg (atol `5e-4`)
  - α `0.02703958` rad (atol `5e-6`)
  - power `= _tgear(throttle)`, not the paper `9.0567`
- Repeat the minimizer from the last `s` while cost `> 1e-7`, at most 100 calls, then raise `RuntimeError`. That is the `trimmerFun` outer loop. One call already finishes on the nominal case.
- Cost weights stay the MATLAB orient-1 weights. `vt_dot` is multiplied by `FT_PER_M` before squaring. α, β, p, q, r derivatives stay in rad/s or rad/s². If the weighted sum `r < 1`, return `sqrt(r)`, as `clf16` does.
- Linearized `A` is 13×13, `B` is 13×4, `C` is 10×13, `D` is 10×4, all SI. Output order is `Nz, q, alpha, theta, Vt, Ny, p, r, beta, phi`. Do not emit the MATLAB `57.3` degree rows. `getLinF16` converts those rows back to radians; the SI `C` kinematic rows are 0/1.
- Finite-difference shrink loop: relative step `0.01 * value` when `value != 0`; tolerance `1e-4`; multiply the step by `0.1` each pass. Zero-value absolute step is the MATLAB `0.5` in that channel's MATLAB unit, converted: angles and surface radians use `0.5 * pi/180`; `Vt` and positions use `0.5 * 0.3048` m; throttle and power use `0.5`. If successive slopes differ by more than `1e6`, raise `RuntimeError`. Do not prompt.
- Bad Mach (`<= 0` or non-finite) or bad height (`< 0` or non-finite) raises `ValueError` in the library and exits 2 in the CLI, one line on stderr, before any search.
- Host tests only: `cd python && python3 -m unittest <module> -v`.
- Each task is one implementer, then one reviewer. Commit commands are in the tasks. Do not commit unless the user has asked for commits in that session; the controller may defer them.
- After the behavior change, UPDATES gets one new top entry `0.85.0`. README changes only the sentences named in Task 5.

```python
"""Wings-level F-16 trim (AeroBench trimmerFun orient 1) on the SI plant."""
from __future__ import annotations

import numpy as np

from f16.model import _tgear, subf16_derivative
from f16.units import DEG_TO_RAD, FT_PER_M


def apply_wings_level(x, u):
    """conf16 orient 1. Returns copies. theta = alpha, phi = p = q = r = 0, pow = tgear."""
    xc = np.asarray(x, dtype=float).copy()
    uc = np.asarray(u, dtype=float).copy()
    xc[3] = 0.0
    xc[4] = xc[1]
    xc[6] = 0.0
    xc[7] = 0.0
    xc[8] = 0.0
    xc[12] = _tgear(float(uc[0]))
    return xc, uc


def wings_level_cost(s, vt_mps: float, height_m: float) -> float:
    """clf16 orient 1. s = [throttle, elevator_deg, alpha_rad]."""
    s = np.asarray(s, dtype=float)
    x = np.zeros(13, dtype=float)
    u = np.zeros(4, dtype=float)
    x[0] = float(vt_mps)
    x[1] = float(s[2])
    x[11] = float(height_m)
    u[0] = float(s[0])
    u[1] = float(s[1]) * DEG_TO_RAD
    x, u = apply_wings_level(x, u)
    xd, _, _ = subf16_derivative(x, u)
    r = 100.0 * (
        (xd[0] * FT_PER_M) ** 2 + xd[1] ** 2 + xd[2] ** 2 + xd[6] ** 2 + xd[7] ** 2 + xd[8] ** 2
    )
    if r < 1.0:
        r = r ** 0.5
    return float(r)
```

import math

from scipy.optimize import minimize

from f16.model import _adc, _tgear, subf16_derivative

NOMINAL_MACH = 0.4511192456
NOMINAL_HEIGHT_M = 304.8
_S0 = np.array([0.2, 0.0, 0.0], dtype=float)


def airspeed_mps(mach: float, height_m: float) -> float:
    amach, _ = _adc(1.0, float(height_m))
    return float(mach) / float(amach)


def _check_condition(mach: float, height_m: float) -> None:
    if not math.isfinite(mach) or mach <= 0.0:
        raise ValueError(f"mach must be positive and finite, got {mach}")
    if not math.isfinite(height_m) or height_m < 0.0:
        raise ValueError(f"height_m must be non-negative and finite, got {height_m}")


def trim_wings_level(mach: float, height_m: float, s0=None):
    """Orient-1 trim. Returns (x_si, u_si, cost)."""
    _check_condition(float(mach), float(height_m))
    vt = airspeed_mps(float(mach), float(height_m))
    s = _S0.copy() if s0 is None else np.asarray(s0, dtype=float).copy()
    height = float(height_m)
    cost = wings_level_cost(s, vt, height)
    for _ in range(100):
        if cost <= 1e-7:
            break
        found = minimize(
            lambda z: wings_level_cost(z, vt, height),
            s,
            method="Nelder-Mead",
            options={"xatol": 1e-9, "fatol": 1e-9, "maxiter": 1000, "adaptive": False},
        )
        s = np.asarray(found.x, dtype=float)
        cost = float(found.fun)
    if cost > 1e-7:
        raise RuntimeError(f"trim did not reach 1e-7, cost {cost}")
    x = np.zeros(13, dtype=float)
    u = np.zeros(4, dtype=float)
    x[0] = vt
    x[1] = float(s[2])
    x[11] = float(height_m)
    u[0] = float(s[0])
    u[1] = float(s[1]) * DEG_TO_RAD
    x, u = apply_wings_level(x, u)
    return x, u, float(cost)
```

Keep a single import block at the top of the file. Do not leave a second `from f16.model import` in the middle. The loop stops early once `cost <= 1e-7`. The check after the loop raises when all 100 attempts stay above that threshold, including a last attempt that succeeds in lowering `s` but not enough.

_ZERO_INPUT_STEP = np.array([0.5, 0.5 * DEG_TO_RAD, 0.5 * DEG_TO_RAD, 0.5 * DEG_TO_RAD], dtype=float)


def _initial_step(value: float, zero_step: float) -> float:
    if value == 0.0:
        return zero_step
    return 0.01 * value


def _slope_column(evaluate, base: np.ndarray, index: int, zero_step: float) -> np.ndarray:
    origin = evaluate(base)
    step = _initial_step(float(base[index]), zero_step)
    previous = np.zeros_like(origin)
    diff = 0.9
    for _ in range(40):
        if diff <= 1e-4:
            break
        bumped = base.copy()
        bumped[index] = float(base[index]) + step
        slope = (evaluate(bumped) - origin) / step
        diff = float(np.max(np.abs(slope - previous)))
        step *= 0.1
        previous = slope
        if diff > 1e6:
            raise RuntimeError(f"linearization did not settle at index {index}")
    else:
        raise RuntimeError(f"linearization did not settle at index {index}")
    return previous


def linearize(x_si, u_si):
    """SI A, B, C, D. y = [Nz, q, alpha, theta, Vt, Ny, p, r, beta, phi]."""
    x0 = np.asarray(x_si, dtype=float).copy()
    u0 = np.asarray(u_si, dtype=float).copy()

    def xd_of_x(x):
        xd, _, _ = subf16_derivative(x, u0)
        return xd

    def nz_ny_of_x(x):
        _, nz, ny = subf16_derivative(x, u0)
        return np.array([nz, ny], dtype=float)

    def xd_of_u(u):
        xd, _, _ = subf16_derivative(x0, u)
        return xd

    def nz_ny_of_u(u):
        _, nz, ny = subf16_derivative(x0, u)
        return np.array([nz, ny], dtype=float)

    A = np.column_stack([_slope_column(xd_of_x, x0, i, float(_ZERO_STATE_STEP[i])) for i in range(13)])
    B = np.column_stack([_slope_column(xd_of_u, u0, i, float(_ZERO_INPUT_STEP[i])) for i in range(4)])
    C = np.zeros((10, 13), dtype=float)
    D = np.zeros((10, 4), dtype=float)
    for i in range(13):
        col = _slope_column(nz_ny_of_x, x0, i, float(_ZERO_STATE_STEP[i]))
        C[0, i] = col[0]
        C[5, i] = col[1]
    for i in range(4):
        col = _slope_column(nz_ny_of_u, u0, i, float(_ZERO_INPUT_STEP[i]))
        D[0, i] = col[0]
        D[5, i] = col[1]
    C[1, 7] = 1.0
    C[2, 1] = 1.0
    C[3, 4] = 1.0
    C[4, 0] = 1.0
    C[6, 6] = 1.0
    C[7, 8] = 1.0
    C[8, 2] = 1.0
    C[9, 3] = 1.0
    return A, B, C, D
```

`_slope_column` must return the last accepted slope once `diff <= 1e-4` at the start of an iteration, which is the slope from the previous, larger step. That matches `jacobFun`: the loop stores `slope1`, shrinks `del`, and exits when the new slope agrees with the stored one. The implementation above exits at the top of the next pass, so `previous` is that stored slope. Do not return the slope from the step that was just shrunk away.

```python
#!/usr/bin/env python3
"""Print a wings-level F-16 trim and its SI state-space matrices."""
from __future__ import annotations

import argparse
import sys
from pathlib import Path

_PY = Path(__file__).resolve().parent
if str(_PY) not in sys.path:
    sys.path.insert(0, str(_PY))

import numpy as np

from f16.trim import airspeed_mps, linearize, trim_wings_level


def _die(message: str) -> None:
    print(message, file=sys.stderr)
    sys.exit(2)


def _block(name: str, matrix: np.ndarray) -> None:
    print(name)
    for row in np.asarray(matrix, dtype=float):
        print(" ".join(f"{value:.8g}" for value in row))


def main(argv: list[str] | None = None) -> None:
    parser = argparse.ArgumentParser(description="Wings-level F-16 trim and SI A,B,C,D")
    parser.add_argument("--mach", type=float, required=True)
    parser.add_argument("--height-m", type=float, required=True)
    parser.add_argument("--npz", type=Path, default=None)
    args = parser.parse_args(argv)
    try:
        x, u, cost = trim_wings_level(args.mach, args.height_m)
        A, B, C, D = linearize(x, u)
    except ValueError as exc:
        _die(str(exc))
    vt = airspeed_mps(args.mach, args.height_m)
    print(f"mach {args.mach}")
    print(f"height_m {args.height_m}")
    print(f"vt_mps {vt:.8g}")
    print(f"cost {cost:.8g}")
    print("x_si " + " ".join(f"{value:.8g}" for value in x))
    print("u_si " + " ".join(f"{value:.8g}" for value in u))
    _block("A", A)
    _block("B", B)
    _block("C", C)
    _block("D", D)
    if args.npz is not None:
        np.savez(args.npz, x=x, u=u, cost=np.array(cost), A=A, B=B, C=C, D=D)


if __name__ == "__main__":
    main()
```
